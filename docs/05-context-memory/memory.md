# Memory

**中文建议：** 记忆  
**成熟度：** 🟡  
**重要程度：** ★★★★★

## 一句话解释

让 Agent 在当前上下文之外保存并在之后取回有用信息的机制。

## 为什么需要它？

上下文窗口有限，而长期任务需要跨会话或跨阶段复用事实、偏好和经验。

## 在 Agent 系统中的位置

通常通过存储 + 检索 + 写入策略实现。

## 最容易混淆

Memory ≠ Context Window；记忆需要在需要时重新进入 Context。
