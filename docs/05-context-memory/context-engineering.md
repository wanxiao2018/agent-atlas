# Context Engineering

**中文建议：** 上下文工程  
**成熟度：** 🟡  
**重要程度：** ★★★★★

## 一句话解释

系统性设计模型在每一步真正看到什么信息，而不只是优化一句 Prompt。

## 为什么需要它？

Agent 的表现很大程度取决于是否把正确的信息在正确的时间放进有限上下文。

## 在 Agent 系统中的位置

覆盖 system instructions、历史、工具结果、检索、压缩等。

## 最容易混淆

Prompt Engineering 更关注提示表达；Context Engineering 更关注整个信息环境。
