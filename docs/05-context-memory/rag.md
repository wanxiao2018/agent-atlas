# RAG

**中文建议：** 检索增强生成  
**成熟度：** 🟢  
**重要程度：** ★★★★☆

## 一句话解释

先从外部知识库检索相关内容，再把结果加入上下文供模型生成答案。

## 为什么需要它？

它让模型使用未固化在参数中的最新或私有知识。

## 在 Agent 系统中的位置

可作为 Agent Retrieval / Memory 的实现方式之一。

## 最容易混淆

RAG 不等于 Memory；RAG 更强调检索外部知识。
