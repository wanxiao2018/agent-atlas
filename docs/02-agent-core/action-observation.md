# Action / Observation

**中文建议：** 行动 / 观察  
**成熟度：** 🟢  
**重要程度：** ★★★★★

## 一句话解释

Action 是 Agent 对外部世界采取的操作；Observation 是执行后返回给 Agent 的结果。

## 为什么需要它？

Agent 通过 Action 改变环境，再通过 Observation 获取反馈，形成闭环。

## 在 Agent 系统中的位置

构成 Agent Loop 的关键反馈通道。

## 最容易混淆

工具调用请求是 Action；工具返回值通常是 Observation。
