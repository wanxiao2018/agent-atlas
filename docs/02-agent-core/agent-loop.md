# Agent Loop

**中文建议：** Agent 循环  
**成熟度：** 🟢  
**重要程度：** ★★★★★

## 一句话解释

让 Agent 反复“观察 → 思考/规划 → 行动 → 再观察”，直到任务完成或触发停止条件的控制循环。

## 为什么需要它？

没有 Loop，模型往往只完成一次响应；有了 Loop，Agent 才能围绕目标连续工作。

## 在 Agent 系统中的位置

Harness 的核心控制结构之一。

## 最容易混淆

Agent Loop ≠ 单次 Chain-of-Thought；它包含真实行动和环境反馈。
