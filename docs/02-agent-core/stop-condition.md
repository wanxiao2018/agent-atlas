# Stop Condition

**中文建议：** 停止条件  
**成熟度：** 🟢  
**重要程度：** ★★★★☆

## 一句话解释

决定 Agent 何时结束循环的规则。

## 为什么需要它？

没有合理停止条件，Agent 可能无意义重试、超时或消耗过多资源。

## 在 Agent 系统中的位置

属于 Agent Loop / Harness 控制逻辑。

## 最容易混淆

任务完成、达到最大步数、预算耗尽、人工终止都可成为停止条件。
