# 贡献指南

## 新增术语

1. 先确认术语是否已有页面。
2. 复制 `reference/term-template.md` 的结构。
3. 文件名统一使用英文小写 kebab-case，例如 `context-engineering.md`。
4. 中文翻译不确定时明确写“暂无统一译法”。
5. 新兴词必须注明成熟度，并尽量给出一手来源。
6. 一次提交尽量只解决一个概念或一组强相关概念。

## 写作原则

- 白话解释优先，但不能牺牲准确性。
- 区分“行业通用定义”和“某家公司自己的定义”。
- 解释概念关系，而不只翻译单词。
- 不把刚流行的新词包装成历史悠久的标准术语。
