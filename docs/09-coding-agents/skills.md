# Skills

**中文建议：** Agent 技能  
**成熟度：** 🟡  
**重要程度：** ★★★★☆

## 一句话解释

把一类可复用任务流程、说明、领域知识或工具使用方式封装成 Agent 可以按需调用或加载的能力单元。

## 为什么需要它？

它让 Agent 不必每次从零理解重复工作，并有助于把复杂能力拆成更小、可维护、可组合的模块。

## 在 Agent 系统中的位置

通常位于 Harness 的能力扩展层，并通过 Context、Tool system 或运行时机制影响 Agent 行为。

## 最容易混淆

“Skill”不是一个跨平台完全统一的技术标准。不同产品可能把它实现为指令包、工具组合、工作流模块或其他形式，阅读时必须结合具体生态。
