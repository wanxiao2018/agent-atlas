# Tracing

**中文建议：** 轨迹追踪 / 链路追踪  
**成熟度：** 🟢  
**重要程度：** ★★★★★

## 一句话解释

记录一次 Agent 运行中模型调用、工具调用、决策步骤和状态变化的过程。

## 为什么需要它？

Agent 失败往往发生在中间某一步，Tracing 帮助定位问题。

## 在 Agent 系统中的位置

是 Observability 与 Evals 的重要数据来源。

## 最容易混淆

日志可以是零散事件；Trace 更强调一次完整运行的链路。
