# Evals

**中文建议：** 评测 / 评估体系  
**成熟度：** 🟢  
**重要程度：** ★★★★★

## 一句话解释

用可重复的方法衡量 Agent 是否正确、稳定、高效地完成目标。

## 为什么需要它？

Agent 输出具有随机性，而且任务通常跨越多步。只看几个成功 demo 很难判断系统是否真的可靠，需要可重复的数据集、指标和评测过程。

## 在 Agent 系统中的位置

Evals 可以覆盖最终任务成功率，也可以评估工具使用、轨迹、成本、延迟、安全行为和中间决策质量。

## 最容易混淆

Evals ≠ 单元测试，但两者可以结合。单元测试更适合确定性代码；Agent Evals 往往还要处理概率输出和多步行为。
