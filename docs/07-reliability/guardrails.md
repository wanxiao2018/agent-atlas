# Guardrails

**中文建议：** 护栏 / 约束机制  
**成熟度：** 🟡  
**重要程度：** ★★★★☆

## 一句话解释

限制、检查或纠正 Agent 输入、输出与行动的安全和质量控制机制。

## 为什么需要它？

Agent 能采取真实行动，因此需要权限、规则、验证和人工确认等边界。

## 在 Agent 系统中的位置

可部署在输入、模型输出、工具调用和执行层。

## 最容易混淆

Guardrails 不是绝对安全保证，而是风险控制层。
