# 学习路线

## Level 1：先看懂 Agent 在干什么

Agent → Agent Loop → Planning → Action / Observation → Stop Condition

## Level 2：看懂 Agent 为什么能真的做事

Harness → Runtime → Tool Calling → Sandbox → State

## Level 3：看懂 Agent 为什么能持续工作

Context Engineering → Memory → RAG → Tracing → Evals

## Level 4：看懂多个 Agent 如何协作

Sub-agent → Handoff → Orchestrator

## Level 5：进入 Agent Engineering

Harness Engineering → Loop Engineering → Coding Agent Skills
