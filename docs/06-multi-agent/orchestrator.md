# Orchestrator

**中文建议：** 编排器 / 调度 Agent  
**成熟度：** 🟡  
**重要程度：** ★★★★☆

## 一句话解释

负责决定任务如何拆分、由哪个 Agent 执行以及如何汇总结果的控制层。

## 为什么需要它？

多个 Agent 如果没有协调，容易重复劳动或上下文冲突。

## 在 Agent 系统中的位置

位于 Multi-agent 系统的协调层。

## 最容易混淆

Orchestrator 可以是固定代码，也可以由模型驱动。
