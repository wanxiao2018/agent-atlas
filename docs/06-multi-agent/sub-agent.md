# Sub-agent

**中文建议：** 子 Agent  
**成熟度：** 🟡  
**重要程度：** ★★★★☆

## 一句话解释

由主 Agent 委派某个子任务、通常具有独立上下文或工具配置的 Agent。

## 为什么需要它？

把复杂任务隔离成更小的责任单元，减少主上下文污染并提升并行能力。

## 在 Agent 系统中的位置

通常受 Orchestrator 或主 Agent 调度。

## 最容易混淆

Sub-agent ≠ 普通函数；它通常拥有自己的模型循环和上下文。
