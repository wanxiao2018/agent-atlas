# Handoff

**中文建议：** 移交 / 任务交接  
**成熟度：** 🟡  
**重要程度：** ★★★★☆

## 一句话解释

一个 Agent 将当前任务、控制权或上下文转交给另一个 Agent 的机制。

## 为什么需要它？

不同 Agent 可以专门处理不同领域，Handoff 让系统在角色之间切换。

## 在 Agent 系统中的位置

Multi-agent 协作中的路由机制。

## 最容易混淆

Handoff 强调控制权转移；Tool Calling 通常仍由当前 Agent 保持控制。
