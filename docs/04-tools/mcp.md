# MCP

**中文建议：** Model Context Protocol（模型上下文协议）  
**成熟度：** 🟡  
**重要程度：** ★★★★★

## 一句话解释

一种让 AI 应用以统一方式连接工具、资源和外部上下文的开放协议。

## 为什么需要它？

不同工具若各自定义接入方式，集成成本很高；协议化可以降低重复适配。

## 在 Agent 系统中的位置

位于 Agent 与外部工具/资源的连接层。

## 最容易混淆

MCP ≠ Agent Framework；它解决连接和上下文互操作问题。
