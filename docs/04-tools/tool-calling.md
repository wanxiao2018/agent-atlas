# Tool Calling

**中文建议：** 工具调用  
**成熟度：** 🟢  
**重要程度：** ★★★★★

## 一句话解释

模型或 Agent 选择并调用外部能力，例如搜索、数据库、终端、浏览器或日历。

## 为什么需要它？

工具让模型从“只会生成内容”扩展到“能获取信息并改变外部系统”。

## 在 Agent 系统中的位置

连接 Model 与真实环境，是 Agent Action 的主要形式。

## 最容易混淆

Tool Calling 是更宽泛概念；Function Calling 常是一种实现接口。
