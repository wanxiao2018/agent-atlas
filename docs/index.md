# Agent Atlas

**Agent / Agentic AI 中文概念地图与入门词典**

Agent Atlas 不是简单的中英术语翻译表，而是一套帮助初学者建立 Agent 工程认知框架的知识库。

每个术语尽量回答六个问题：

1. 它一句话是什么意思？
2. 为什么 Agent 领域需要它？
3. 它和其他概念是什么关系？
4. 最容易和什么混淆？
5. 在真实 Agent 系统里它长什么样？
6. 这是成熟术语，还是正在形成的新兴说法？

## 从这张图开始

```text
Agent
├── Model
├── Context
└── Harness
    ├── Agent Loop
    ├── Tools
    ├── Runtime
    ├── State / Memory
    ├── Sandbox
    ├── Permissions
    ├── Tracing / Evals
    └── Stop Conditions
```

推荐第一次进入本项目时按以下顺序阅读：

**Agent → Agent Loop → Harness → Runtime → Sandbox → Tool Calling → Context Engineering → Memory → Handoff → Evals → Harness Engineering → Loop Engineering**

> 本项目会持续更新。Agent 领域术语变化很快，因此我们会区分“稳定术语”和“新兴术语”。
