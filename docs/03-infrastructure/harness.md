# Agent Harness

**中文建议：** Agent 运行框架 / 外围执行系统  
**成熟度：** 🟡  
**重要程度：** ★★★★★

## 一句话解释

包裹模型并负责循环、工具、上下文、状态、权限和执行控制，使模型真正成为可工作的 Agent 的外围系统。

## 为什么需要它？

单独的模型通常不能自己访问文件、执行代码、维护状态或自动重试，这些能力由 Harness 组织起来。

## 在 Agent 系统中的位置

Agent ≈ Model + Harness（简化理解）。

## 最容易混淆

Harness ≠ Model；Harness 也不等于单一 Sandbox 或某个工具。
