# Runtime

**中文建议：** 运行时  
**成熟度：** 🟢  
**重要程度：** ★★★★★

## 一句话解释

Agent 实际执行代码、工具调用和任务逻辑时所处的运行环境与生命周期管理层。

## 为什么需要它？

Agent 不只是“想”，还必须在某个环境里真正执行动作。

## 在 Agent 系统中的位置

通常由 Harness 管理，并连接工具、Sandbox、状态存储。

## 最容易混淆

Runtime 是执行环境；Harness 是更上层的控制与组织系统。
