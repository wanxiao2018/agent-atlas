# State

**中文建议：** 状态  
**成熟度：** 🟢  
**重要程度：** ★★★★☆

## 一句话解释

Agent 在任务过程中需要持续保存的当前信息，例如步骤、变量、文件、任务进度或会话数据。

## 为什么需要它？

没有状态，Agent 很难跨步骤保持一致性。

## 在 Agent 系统中的位置

与 Memory、Checkpoint、Session 紧密相关。

## 最容易混淆

State 更偏当前任务运行数据；Memory 更强调可在之后检索和复用的信息。
