# Sandbox

**中文建议：** 沙箱  
**成熟度：** 🟢  
**重要程度：** ★★★★★

## 一句话解释

把 Agent 的代码执行、文件操作或命令限制在受控边界内的隔离环境。

## 为什么需要它？

Agent 会执行不完全可预测的操作，因此需要降低对宿主机、凭据和生产环境的风险。

## 在 Agent 系统中的位置

通常是 Runtime 的受控执行区域。

## 最容易混淆

Sandbox ≠ Runtime；Runtime 可以包含 Sandbox。
