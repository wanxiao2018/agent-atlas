# Agent

**中文建议：** 智能体  
**成熟度：** 🟡  
**重要程度：** ★★★★★

## 一句话解释

能够围绕目标进行多步决策，并通过工具或环境采取行动的软件系统。

## 为什么需要它？

LLM 负责生成与推理；Agent 则在模型之外加入循环、工具、状态和执行环境，使系统可以持续完成任务。

## 在 Agent 系统中的位置

Agent ≈ Model + Context + Harness。

## 最容易混淆

聊天模型通常一次输入一次输出；Agent 强调目标驱动的多步行动。
