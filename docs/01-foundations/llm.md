# LLM

**中文建议：** 大语言模型  
**成熟度：** 🟢  
**重要程度：** ★★★★★

## 一句话解释

根据上下文预测并生成文本或结构化输出的语言模型。

## 为什么需要它？

在 Agent 中，LLM 常充当推理与决策核心，但它本身不等于完整 Agent。

## 在 Agent 系统中的位置

通常位于 Agent 的 Model 层。

## 最容易混淆

LLM ≠ Agent；模型会生成输出，Agent 系统还负责执行与循环。
